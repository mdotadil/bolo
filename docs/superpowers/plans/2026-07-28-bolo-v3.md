# Bolo v3 "Her Voice Grows + Product Track" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add parent voice recording, a five-language board (en/ur/ar/fr/es), More-words pages, local usage insights, a type-to-speak parent tool, and backup/restore to the shipped Bolo v1 AAC app — plus the product track: a store|sideload channel split, Crashlytics + a closed 9-event Analytics taxonomy, child-safety build flags, and a one-time supporter unlock IAP gating only the insights PDF export. One release: 3.0.0. (This plan supersedes the v2 plan; v2 never ships.)

**Architecture:** All state stays in the existing `Board` JSON + Riverpod `BoardNotifier` pattern; the family track adds a versioned migration in `BoardStore`, a separate debounced `UsageStore`, and two new audio seams (`Recorder`, `RecordingPlayer`) mirroring the v1 `Tts` seam. Child-facing UI gains only labels-by-language, a fixed "More…" tile, and a zero-animation More page; everything else lives behind the grown-up gate. The product track hangs off one compile-time const, `appChannel` (`BOLO_CHANNEL`): a `SettingsStore` (consent + entitlement in its own settings.json), a store-only Firebase bootstrap in main.dart, a `TelemetryService` with a closed event enum (injectable sink for tests), and a `PurchaseService` behind a `PurchaseGateway` seam. In the sideload channel the const gate makes every product-track branch dead code.

**Tech Stack:** Flutter 3.44.2 / Dart 3.12 — v1 five: flutter_riverpod, flutter_tts, flutter_svg, path_provider, image_picker; family five: record, audioplayers, archive, share_plus, file_selector; product five: firebase_core, firebase_crashlytics, firebase_analytics, in_app_purchase, pdf.

**Spec:** `docs/superpowers/specs/2026-07-28-bolo-v3-design.md` (approved). Read its "Non-goals" and "Channels" sections before inventing anything.

## Global Constraints

- Work on branch `feature/v3`, cut from `main` (never from dev).
- Dependencies: EXACTLY fifteen — the v1 five (flutter_riverpod, flutter_tts, flutter_svg, path_provider, image_picker) plus EXACTLY five family packages (record, audioplayers, archive, share_plus, file_selector) plus EXACTLY five product packages (firebase_core, firebase_crashlytics, firebase_analytics, in_app_purchase, pdf). flutter_lints stays dev-only. No codegen, nothing else. This list is CLOSED.
- **Channel rules.** `appChannel` (from `--dart-define=BOLO_CHANNEL=store|sideload`, default `sideload`; Task 14) is the master gate for the whole product track. Sideload = the family build: `Firebase.initializeApp` is NEVER called, no IAP gateway is ever constructed, every feature is unlocked, fully offline — behavior identical to a build with no product track. Store = the Play build: Firebase bootstrap, diagnostics toggle, supporter unlock. **The child board never imports telemetry:** no file under `lib/features/board/` may reference `telemetry_service` — a guard test (Task 19) enforces this in CI.
- **The board never rearranges itself.** No feature may change existing card order, position, or grid placement. The "More…" tile is always the LAST grid position.
- Sensory rules: muted palette from `lib/theme.dart` only; no animation except the 150 ms tap highlight — child-facing navigation (More page) uses zero-duration routes; no sounds except speech (recordings are speech); portrait stays locked.
- `const supportedLanguages = ['en', 'ur', 'ar', 'fr', 'es']` (top-level in `lib/models/board.dart`, Task 1) is the SINGLE SOURCE OF TRUTH for languages: the parent language dropdown, the record-sheet rows, the `_ttsTag` map, and the migration merge all derive from it. TTS tags: `en` → `en-US`, `ur` → `ur-PK`, `ar` → `ar-SA`, `fr` → `fr-FR`, `es` → `es-ES`.
- One active language at a time (`Board.activeLanguage`, any member of `supportedLanguages`). The child never sees mixed-language UI. ur/ar render RTL via the existing directional primitives.
- All card/category display strings come from `labels`/`names` maps. Fixed UI chrome may use small const language-keyed maps (e.g. the More… tile label, `languageDisplayNames`).
- RTL-safe: `EdgeInsetsDirectional`, `AlignmentDirectional`, leading/trailing. Never left/right variants.
- Errors are never surfaced on the child screen (calm blank / silent skip). Persistence failures keep the in-memory board.
- Speech interrupt rule: a new tap stops ALL current audio (TTS and recorded) before speaking. Nothing queues.
- Speech resolution order: recording(activeLanguage) → TTS(activeLanguage label) → TTS(en label).
- Testing gotcha (cost v1 three review rounds): real dart:io writes never complete inside testWidgets' FakeAsync zone, and `pumpAndSettle` inside `tester.runAsync` deadlocks. Wrap disk-touching widget interactions in `tester.runAsync` with bounded `tester.pump(...)` calls. See `test/features/parent_screen_test.dart` for the working pattern.
- Every task: `flutter analyze` must be clean, full `flutter test` green before its commit.
- Commits end with: `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`
- Existing tests must keep passing; when a constructor/signature changes (Task 5 changes `SpeechService`), the same task updates every call site and test.

```dart
/// The closed set of board languages, in parent-UI order. SINGLE SOURCE OF
/// TRUTH: the language dropdown, record-sheet rows, the TTS tag map, and the
/// migration merge all derive from this list. Adding a language later means
/// adding it here + a `_ttsTag` entry + a `languageDisplayNames` entry +
/// default-board labels; nothing else.
const supportedLanguages = ['en', 'ur', 'ar', 'fr', 'es'];

class SymbolCard {
  final String id;
  final Map<String, String> labels;
  final String? symbolAsset;
  final String? photoPath;
  final bool hidden;
  final Map<String, String> recordings;

  const SymbolCard({
    required this.id,
    required this.labels,
    this.symbolAsset,
    this.photoPath,
    this.hidden = false,
    this.recordings = const {},
  });

  SymbolCard copyWith(
          {bool? hidden,
          Map<String, String>? recordings,
          Map<String, String>? labels}) =>
      SymbolCard(
        id: id,
        labels: labels ?? this.labels,
        symbolAsset: symbolAsset,
        photoPath: photoPath,
        hidden: hidden ?? this.hidden,
        recordings: recordings ?? this.recordings,
      );

  factory SymbolCard.fromJson(Map<String, dynamic> json) => SymbolCard(
        id: json['id'] as String,
        labels: Map<String, String>.from(json['labels'] as Map),
        symbolAsset: json['symbolAsset'] as String?,
        photoPath: json['photoPath'] as String?,
        hidden: json['hidden'] as bool? ?? false,
        recordings: json['recordings'] == null
            ? const {}
            : Map<String, String>.from(json['recordings'] as Map),
      );

  Map<String, dynamic> toJson() => {
        'id': id,
        'labels': labels,
        if (symbolAsset != null) 'symbolAsset': symbolAsset,
        if (photoPath != null) 'photoPath': photoPath,
        if (hidden) 'hidden': hidden,
        if (recordings.isNotEmpty) 'recordings': recordings,
      };
}

class BoardCategory {
  final String id;
  final Map<String, String> names;
  final List<SymbolCard> cards;
  final List<SymbolCard> moreCards;

  const BoardCategory(
      {required this.id,
      required this.names,
      required this.cards,
      this.moreCards = const []});

  BoardCategory copyWith(
          {List<SymbolCard>? cards, List<SymbolCard>? moreCards}) =>
      BoardCategory(
          id: id,
          names: names,
          cards: cards ?? this.cards,
          moreCards: moreCards ?? this.moreCards);

  factory BoardCategory.fromJson(Map<String, dynamic> json) => BoardCategory(
        id: json['id'] as String,
        names: Map<String, String>.from(json['names'] as Map),
        cards: (json['cards'] as List)
            .map((c) => SymbolCard.fromJson(c as Map<String, dynamic>))
            .toList(),
        moreCards: json['moreCards'] == null
            ? const []
            : (json['moreCards'] as List)
                .map((c) => SymbolCard.fromJson(c as Map<String, dynamic>))
                .toList(),
      );

  Map<String, dynamic> toJson() => {
        'id': id,
        'names': names,
        'cards': cards.map((c) => c.toJson()).toList(),
        if (moreCards.isNotEmpty)
          'moreCards': moreCards.map((c) => c.toJson()).toList(),
      };
}

class Board {
  static const currentVersion = 2;

  final int version;
  final double speechRate;
  final String activeLanguage;
  final List<BoardCategory> categories;

  const Board({
    required this.speechRate,
    required this.categories,
    this.version = currentVersion,
    this.activeLanguage = 'en',
  });

  Board copyWith(
          {double? speechRate,
          List<BoardCategory>? categories,
          String? activeLanguage}) =>
      Board(
        version: currentVersion,
        speechRate: speechRate ?? this.speechRate,
        activeLanguage: activeLanguage ?? this.activeLanguage,
        categories: categories ?? this.categories,
      );

  factory Board.fromJson(Map<String, dynamic> json) => Board(
        version: currentVersion,
        speechRate: ((json['speechRate'] as num?)?.toDouble() ?? 0.45)
            .clamp(0.3, 0.7)
            .toDouble(),
        activeLanguage: json['activeLanguage'] as String? ?? 'en',
        categories: (json['categories'] as List)
            .map((c) => BoardCategory.fromJson(c as Map<String, dynamic>))
            .toList(),
      );

  Map<String, dynamic> toJson() => {
        'version': version,
        'speechRate': speechRate,
        'activeLanguage': activeLanguage,
        'categories': categories.map((c) => c.toJson()).toList(),
      };
}
```

Note: `Board.fromJson` normalizes `version` to 2 — whether the FILE was v1 is decided in `BoardStore.load()` by inspecting the raw json before parsing (Task 2), not here.

```dart
    if (_file.existsSync()) {
      try {
        final raw =
            jsonDecode(await _file.readAsString()) as Map<String, dynamic>;
        final board = Board.fromJson(raw);
        final fileVersion = raw['version'] as int? ?? 1;
        if (fileVersion >= Board.currentVersion) return board;
        final migrated = _migrate(board,
            Board.fromJson(jsonDecode(await _loadDefault()) as Map<String, dynamic>));
        await save(migrated);
        return migrated;
      } catch (_) {

        try {
          _file.renameSync('${_file.path}.corrupt');
        } catch (_) {}
      }
    }
    return Board.fromJson(jsonDecode(await _loadDefault()) as Map<String, dynamic>);

  /// v1 → v2: merge every shipped label/name language set (ur/ar/fr/es) and
  /// default More cards from the bundled default board, by id. Never changes
  /// card order, hidden flags, or custom cards. Board.fromJson already
  /// stamped version/activeLanguage defaults.
  Board _migrate(Board old, Board def) {
    final defCats = {for (final c in def.categories) c.id: c};
    return old.copyWith(categories: [
      for (final cat in old.categories)
        _mergeCategory(cat, defCats[cat.id]),
    ]);
  }

  BoardCategory _mergeCategory(BoardCategory cat, BoardCategory? def) {
    if (def == null) return cat;
    final defCards = {for (final c in [...def.cards, ...def.moreCards]) c.id: c};
    List<SymbolCard> mergeLabels(List<SymbolCard> cards) => [
          for (final card in cards)
            defCards[card.id] == null
                ? card
                : card.copyWith(labels: {
                    ...defCards[card.id]!.labels,
                    ...card.labels,
                  }),
        ];
    return BoardCategory(
      id: cat.id,
      names: {...def.names, ...cat.names},
      cards: mergeLabels(cat.cards),
      moreCards:
          cat.moreCards.isEmpty ? def.moreCards : mergeLabels(cat.moreCards),
    );
  }
```

```dart
import 'dart:convert';
import 'dart:io';

class CardUsage {
  final int count;
  final DateTime firstUsed;
  final DateTime lastUsed;
  const CardUsage(
      {required this.count, required this.firstUsed, required this.lastUsed});
}

class UsageData {
  final Map<String, CardUsage> perCard;
  final Map<String, int> perDay;
  const UsageData({required this.perCard, required this.perDay});
}

/// On-device tap counters. Separate file from board.json on purpose: a corrupt
/// counter file must never take the board down, and taps write on a different
/// cadence (debounced) than board edits.
class UsageStore {
  UsageStore(this._dir, {DateTime Function()? clock})
      : _clock = clock ?? DateTime.now;

  static const _flushEvery = 5;
  static const _keepDays = 90;

  final Directory _dir;
  final DateTime Function() _clock;
  final List<(String, DateTime)> _buffer = [];

  File get _file => File('${_dir.path}/usage.json');

  void recordTap(String cardId) {
    _buffer.add((cardId, _clock()));
    if (_buffer.length >= _flushEvery) {
      flush(); // fire and forget; speech must never wait on disk
    }
  }

  Future<void> flush() async {
    if (_buffer.isEmpty) return;
    final taps = List.of(_buffer);
    _buffer.clear();
    try {
      final raw = _readRaw();
      final perCard =
          (raw['perCard'] as Map<String, dynamic>?) ?? <String, dynamic>{};
      final perDay =
          (raw['perDay'] as Map<String, dynamic>?) ?? <String, dynamic>{};
      for (final (id, at) in taps) {
        final prev = perCard[id] as Map<String, dynamic>?;
        perCard[id] = {
          'count': ((prev?['count'] as int?) ?? 0) + 1,
          'firstUsed': (prev?['firstUsed'] as String?) ?? at.toIso8601String(),
          'lastUsed': at.toIso8601String(),
        };
        final day = _dayKey(at);
        perDay[day] = ((perDay[day] as int?) ?? 0) + 1;
      }
      final cutoff = _clock().subtract(const Duration(days: _keepDays));
      perDay.removeWhere((day, _) => DateTime.parse(day).isBefore(cutoff));
      final tmpFile = File('${_file.path}.tmp');
      await tmpFile.writeAsString(
          jsonEncode({'perCard': perCard, 'perDay': perDay}),
          flush: true);
      tmpFile.renameSync(_file.path);
    } catch (_) {
      // Counters are best-effort; never let them break anything.
    }
  }

  Future<UsageData> load() async {
    final raw = _readRaw();
    final perCard = <String, CardUsage>{};
    ((raw['perCard'] as Map<String, dynamic>?) ?? {}).forEach((id, v) {
      final m = v as Map<String, dynamic>;
      perCard[id] = CardUsage(
        count: m['count'] as int,
        firstUsed: DateTime.parse(m['firstUsed'] as String),
        lastUsed: DateTime.parse(m['lastUsed'] as String),
      );
    });
    final perDay = <String, int>{};
    ((raw['perDay'] as Map<String, dynamic>?) ?? {})
        .forEach((day, n) => perDay[day] = n as int);
    return UsageData(perCard: perCard, perDay: perDay);
  }

  Map<String, dynamic> _readRaw() {
    if (!_file.existsSync()) return {};
    try {
      return jsonDecode(_file.readAsStringSync()) as Map<String, dynamic>;
    } catch (_) {
      try {
        _file.renameSync('${_file.path}.corrupt');
      } catch (_) {}
      return {};
    }
  }

  static String _dayKey(DateTime d) =>
      '${d.year.toString().padLeft(4, '0')}-${d.month.toString().padLeft(2, '0')}-${d.day.toString().padLeft(2, '0')}';
}
```

```dart
abstract class Recorder {
  Future<bool> hasPermission();
  Future<void> start(String path);

  /// Returns the recorded file's path, or null if not recording / failed.
  Future<String?> stop();
  bool get isRecording;
}

class RecordPackageRecorder implements Recorder {
  final AudioRecorder _rec = AudioRecorder();
  bool _recording = false;

  @override
  bool get isRecording => _recording;

  @override
  Future<bool> hasPermission() => _rec.hasPermission();

  @override
  Future<void> start(String path) async {
    await _rec.start(
        const RecordConfig(encoder: AudioEncoder.aacLc, numChannels: 1),
        path: path);
    _recording = true;

  @override
  Future<String?> stop() async {
    if (!_recording) return null;
    _recording = false;
    try {
      return await _rec.stop();
    } catch (_) {
      return null;
    }
```

```dart
import 'dart:io';
import 'package:flutter_tts/flutter_tts.dart';
import '../models/board.dart';
import 'recording_player.dart';

abstract class Tts {
  Future<void> init();
  Future<void> setSpeechRate(double rate);
  Future<void> stop();
  Future<void> speak(String text);
  Future<void> setLanguage(String tag);
  Future<bool> isLanguageAvailable(String tag);
}

/// Production adapter. The iOS audio category is the load-bearing part:
/// `playback` makes speech audible with the silent switch on.
class FlutterTtsAdapter implements Tts {
  final FlutterTts _tts = FlutterTts();

  @override
  Future<void> init() async {
    if (Platform.isIOS) {
      await _tts.setSharedInstance(true);
      await _tts.setIosAudioCategory(
        IosTextToSpeechAudioCategory.playback,
        [IosTextToSpeechAudioCategoryOptions.duckOthers],
        IosTextToSpeechAudioMode.defaultMode,
      );
    }
    await _tts.setLanguage('en-US');
    await _tts.awaitSpeakCompletion(false);
  }

  @override
  Future<void> setSpeechRate(double rate) => _tts.setSpeechRate(rate);
  @override
  Future<void> stop() => _tts.stop();
  @override
  Future<void> speak(String text) => _tts.speak(text);
  @override
  Future<void> setLanguage(String tag) => _tts.setLanguage(tag);
  @override
  Future<bool> isLanguageAvailable(String tag) async =>
      (await _tts.isLanguageAvailable(tag)) == true;
}

class SpeechService {
  SpeechService(this._tts, this._player, {required Directory docsDir})
      : _docsDir = docsDir;

  /// One entry per supportedLanguages member (kept in the same order).
  static const _ttsTag = {
    'en': 'en-US',
    'ur': 'ur-PK',
    'ar': 'ar-SA',
    'fr': 'fr-FR',
    'es': 'es-ES',
  };

  final Tts _tts;
  final RecordingPlayer _player;
  final Directory _docsDir;
  bool _initialized = false;

  Future<void> configure({required double rate, String language = 'en'}) async {
    if (!_initialized) {
      await _tts.init();
      _initialized = true;
    }
    await _tts.setSpeechRate(rate);
    await _tts.setLanguage(_ttsTag[language] ?? 'en-US');
  }

  /// Whether the device has a TTS voice for [language] (a supportedLanguages
  /// code). Drives the parent-mode "voice not available" note.
  Future<bool> languageAvailable(String language) =>
      _tts.isLanguageAvailable(_ttsTag[language] ?? 'en-US');

  /// New speech always interrupts everything; nothing queues.
  Future<void> stopAll() async {
    await _player.stop();
    await _tts.stop();
  }

  Future<void> speakCard(SymbolCard card, {required String language}) async {
    final relative = card.recordings[language];
    if (relative != null) {
      final file = File('${_docsDir.path}/$relative');
      if (file.existsSync()) {
        await stopAll();
        await _player.play(file.path);
        return;
      }
    }
    final label = card.labels[language];
    if (label != null && label.isNotEmpty) {
      await _speak(label, language);
      return;
    }
    final en = card.labels['en'];
    if (en == null || en.isEmpty) return; // calm silence, never an error
    await _speak(en, 'en');
  }

  Future<void> speakText(String text, {required String language}) async {
    final trimmed = text.trim();
    if (trimmed.isEmpty) return;
    await _speak(trimmed, language);
  }

  Future<void> _speak(String text, String language) async {
    await stopAll();
    await _tts.setLanguage(_ttsTag[language] ?? 'en-US');
    await _tts.speak(text);
  }
}
```

```dart
class InsightsSection extends ConsumerWidget {
  const InsightsSection({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final boardAsync = ref.watch(boardNotifierProvider);
    return boardAsync.maybeWhen(
      orElse: () => const SizedBox.shrink(),
      data: (board) => FutureBuilder<UsageData>(
        future: ref.read(usageStoreProvider).load(),

          if (!snap.hasData) return const SizedBox.shrink();
          final usage = snap.data!;
          final labels = _labelIndex(board);
          final now = DateTime.now();

          final weekCount = usage.perDay.entries
              .where((e) =>
                  DateTime.parse(e.key)
                      .isAfter(now.subtract(const Duration(days: 7))))
              .fold<int>(0, (sum, e) => sum + e.value);

          final top = usage.perCard.entries.toList()
            ..sort((a, b) => b.value.count.compareTo(a.value.count));
          final top5 = top.take(5).toList();
          final maxCount = top5.isEmpty ? 1 : top5.first.value.count;

          final newWords = usage.perCard.entries
              .where((e) => e.value.firstUsed
                  .isAfter(now.subtract(const Duration(days: 14))))
              .map((e) => labels[e.key] ?? e.key)
              .toList();

          return Column(
            key: const ValueKey('insights-section'),
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('Insights',

              const SizedBox(height: 8),

              const SizedBox(height: 8),
              for (final e in top5)
```

```dart
import 'dart:async';

/// Parent-facing display names, one entry per supportedLanguages member.
/// Shared with the language dropdown in parent_screen.dart (Task 10).
const languageDisplayNames = {
  'en': 'English',
  'ur': 'اردو',
  'ar': 'العربية',
  'fr': 'Français',
  'es': 'Español',
};

void showRecordSheet(BuildContext context, WidgetRef ref, SymbolCard card) {
  showModalBottomSheet<void>(
    context: context,
    isScrollControlled: true,
    builder: (_) => _RecordSheet(card: card),
  );
}

class _RecordSheet extends ConsumerStatefulWidget {
  const _RecordSheet({required this.card});
  final SymbolCard card;
  @override
  ConsumerState<_RecordSheet> createState() => _RecordSheetState();
}

class _RecordSheetState extends ConsumerState<_RecordSheet> {
  // Rows derive from supportedLanguages — no per-language list here.
  static const _maxSeconds = 10;

  String? _recordingLang;
  int _elapsed = 0;
  Timer? _ticker;
  late final TextEditingController _en;
  late final TextEditingController _ur;

  bool get _isCustom => widget.card.photoPath != null;

  @override
  void initState() {
    super.initState();
    _en = TextEditingController(text: widget.card.labels['en'] ?? '');
    _ur = TextEditingController(text: widget.card.labels['ur'] ?? '');
  }

  @override
  void dispose() {
    _ticker?.cancel();
    _en.dispose();
    _ur.dispose();
    super.dispose();
  }

  /// The live card from the provider, so recording changes render immediately.
  SymbolCard get _card {
    final board = ref.watch(boardNotifierProvider).value;
    if (board == null) return widget.card;
    for (final cat in board.categories) {
      for (final c in [...cat.cards, ...cat.moreCards]) {
        if (c.id == widget.card.id) return c;
      }
    }
    return widget.card;
  }

  Future<void> _start(String lang) async {
    final recorder = ref.read(recorderProvider);
    if (!await recorder.hasPermission()) return;
    final docs = ref.read(docsDirProvider);
    Directory('${docs.path}/recordings').createSync(recursive: true);
    final tmpPath = '${docs.path}/recordings/${widget.card.id}_$lang.m4a.tmp';
    await recorder.start(tmpPath);
    if (!mounted) return;
    setState(() {
      _recordingLang = lang;
      _elapsed = 0;
    });
    _ticker = Timer.periodic(const Duration(seconds: 1), (t) {
      if (!mounted) return;
      setState(() => _elapsed++);
      if (_elapsed >= _maxSeconds) _stop(lang);
    });
  }

  Future<void> _stop(String lang) async {
    _ticker?.cancel();
    final recorder = ref.read(recorderProvider);
    final tmpPath = await recorder.stop();
    if (!mounted) return;
    setState(() => _recordingLang = null);
    if (tmpPath == null) return;
    final finalPath = tmpPath.replaceFirst(RegExp(r'\.tmp$'), '');
    try {
      File(tmpPath).renameSync(finalPath);
    } catch (_) {
      return; // failed save = no recording; card unchanged
    }
    await ref.read(boardNotifierProvider.notifier).setRecording(
        widget.card.id, lang, 'recordings/${widget.card.id}_$lang.m4a');
  }

  Future<void> _play(String lang) async {
    final rel = _card.recordings[lang];
    if (rel == null) return;
    final docs = ref.read(docsDirProvider);
    await ref.read(recordingPlayerProvider).play('${docs.path}/$rel');
  }

  Future<void> _delete(String lang) async {
    final rel = _card.recordings[lang];
    if (rel != null) {
      final docs = ref.read(docsDirProvider);
      try {
        File('${docs.path}/$rel').deleteSync();
      } catch (_) {}
    }
    await ref
        .read(boardNotifierProvider.notifier)
        .removeRecording(widget.card.id, lang);
  }

  @override
  Widget build(BuildContext context) {
    final card = _card;
```

In `parent_screen.dart`, add the pure translation function at top level (exported for the unit test):

```dart
enum ReorderAction { mainReorder, moreReorder, moveToMore, moveToMain, none }

/// Translates ReorderableListView indices over the combined
/// [main..., divider, more...] children list into a section-level action.
/// Returns (action, oldIndex, newIndex) in SECTION-LOCAL indices.
(ReorderAction, int, int) translateReorder(
    int mainCount, int oldIndex, int newIndex) {
  final divider = mainCount;
  if (oldIndex == divider) return (ReorderAction.none, 0, 0);
  final fromMain = oldIndex < divider;
  // onReorderItem semantics: newIndex is already adjusted for removal.
  final toMain = newIndex <= divider - (fromMain ? 1 : 0);
  if (fromMain && toMain) return (ReorderAction.mainReorder, oldIndex, newIndex);
  if (!fromMain && !toMain) {
    return (
      ReorderAction.moreReorder,
      oldIndex - divider - 1,
      newIndex - divider - 1,
    );
  }
  if (fromMain) {
    return (ReorderAction.moveToMore, oldIndex, 0);
  }
  return (ReorderAction.moveToMain, oldIndex - divider - 1, newIndex);
}
```

```dart
import 'dart:convert';
import 'dart:io';
import 'package:archive/archive_io.dart';
import '../models/board.dart';

/// Creates and restores `.bolo` backups: a zip of board.json, usage.json,
/// photos/ and recordings/. Restore is staged: nothing in the live docs dir
/// changes until the archive has fully validated.
class BackupService {
  BackupService(this._docsDir);
  final Directory _docsDir;

  Future<File> createBackup() async {
    final archive = Archive();
    void addFile(String relative) {
      final f = File('${_docsDir.path}/$relative');
      if (!f.existsSync()) return;
      final bytes = f.readAsBytesSync();
      archive.addFile(ArchiveFile(relative, bytes.length, bytes));
    }

    addFile('board.json');
    addFile('usage.json');
    for (final dir in ['photos', 'recordings']) {
      final d = Directory('${_docsDir.path}/$dir');
      if (!d.existsSync()) continue;
      for (final f in d.listSync().whereType<File>()) {
        addFile('$dir/${f.uri.pathSegments.last}');
      }
    }

    final now = DateTime.now();
    final name = 'bolo-backup-${now.year.toString().padLeft(4, '0')}-'
        '${now.month.toString().padLeft(2, '0')}-'
        '${now.day.toString().padLeft(2, '0')}.bolo';
    final out = File('${Directory.systemTemp.path}/$name');
    out.writeAsBytesSync(ZipEncoder().encode(archive));
    return out;
  }

  Future<void> restore(File backupFile) async {
    final Archive archive;
    try {
      archive = ZipDecoder().decodeBytes(backupFile.readAsBytesSync());
    } catch (_) {
      throw const FormatException('Not a Bolo backup file.');
    }

    final boardEntry = archive.findFile('board.json');
    if (boardEntry == null) {
      throw const FormatException('Backup contains no board.');
    }
    final Board board;
    try {
      board = Board.fromJson(jsonDecode(utf8.decode(boardEntry.content))
          as Map<String, dynamic>);
    } catch (_) {
      throw const FormatException('Backup board is not readable.');
    }

    // Stage everything first; only touch the live dir after full success.
    final staging = Directory.systemTemp.createTempSync('bolo_restore');
    try {
      for (final entry in archive.files.where((f) => f.isFile)) {
        final out = File('${staging.path}/${entry.name}');
        out.parent.createSync(recursive: true);
        out.writeAsBytesSync(entry.content);
      }

      // Re-anchor photo paths to THIS device's docs dir.
      final reanchored = board.copyWith(categories: [
        for (final cat in board.categories)
          cat.copyWith(
            cards: [for (final c in cat.cards) _reanchor(c)],
            moreCards: [for (final c in cat.moreCards) _reanchor(c)],
          )
      ]);
      File('${staging.path}/board.json')
          .writeAsStringSync(jsonEncode(reanchored.toJson()));

      // Swap into place.
      for (final dir in ['photos', 'recordings']) {
        final target = Directory('${_docsDir.path}/$dir');
        final staged = Directory('${staging.path}/$dir');
        if (target.existsSync()) target.deleteSync(recursive: true);
        if (staged.existsSync()) {
          target.createSync(recursive: true);
          for (final f in staged.listSync().whereType<File>()) {
            f.copySync('${target.path}/${f.uri.pathSegments.last}');
          }
        }
      }
      for (final name in ['board.json', 'usage.json']) {
        final staged = File('${staging.path}/$name');
        if (staged.existsSync()) {
          staged.copySync('${_docsDir.path}/$name');
        }
      }
    } finally {
      try {
        staging.deleteSync(recursive: true);
      } catch (_) {}
    }
  }

  SymbolCard _reanchor(SymbolCard card) {
    final photo = card.photoPath;
    if (photo == null) return card;
    final base = photo.split('/').last;
    // SymbolCard has no copyWith(photoPath:) — rebuild explicitly.
    return SymbolCard(
      id: card.id,
      labels: card.labels,
      symbolAsset: card.symbolAsset,
      photoPath: '${_docsDir.path}/photos/$base',
      hidden: card.hidden,
      recordings: card.recordings,
    );
  }
}
```

```dart
/// Build-time distribution channel.
///
/// sideload (default): the family build. Firebase is NEVER initialized, no
/// IAP is ever constructed, every feature is unlocked, fully offline.
/// store: the Play build. Firebase bootstrap + diagnostics toggle +
/// supporter unlock.
enum AppChannel { sideload, store }

const String _rawChannel =
    String.fromEnvironment('BOLO_CHANNEL', defaultValue: 'sideload');

/// Master gate for the product track. A compile-time const: in sideload
/// builds every `appChannel == AppChannel.store` branch is dead code and is
/// tree-shaken out of the family APK.
///
/// Dart has no const functions, so this expression and [parseChannel] MUST
/// stay textually in sync.
const AppChannel appChannel =
    _rawChannel == 'store' ? AppChannel.store : AppChannel.sideload;

/// Runtime mirror of the [appChannel] const expression, unit-testable for
/// both parse paths (the const itself is fixed by --dart-define at compile
/// time and cannot be varied inside one test binary).
AppChannel parseChannel(String raw) =>
    raw == 'store' ? AppChannel.store : AppChannel.sideload;
```

```dart
import 'dart:io';
import 'package:flutter_riverpod/flutter_riverpod.dart';

/// Parent-scoped app settings. Deliberately a SEPARATE file from board.json:
/// 1. Backups (.bolo) zip board.json + media and must NOT carry consent or
///    entitlement onto another phone (a restore must not flip that phone's
///    privacy choice or grant a purchase that wasn't made there) — so
///    settings.json is excluded from BackupService on purpose.
/// 2. board.json's corrupt-reset path rebuilds the board from defaults; that
///    path must never silently reset a parent's telemetry opt-out.
class Settings {
  final bool telemetryEnabled; // store channel: diagnostics consent
  final bool supporterUnlocked; // store channel: one-time IAP entitlement

  const Settings({
    this.telemetryEnabled = true,
    this.supporterUnlocked = false,
  });

  Settings copyWith({bool? telemetryEnabled, bool? supporterUnlocked}) =>
      Settings(
        telemetryEnabled: telemetryEnabled ?? this.telemetryEnabled,
        supporterUnlocked: supporterUnlocked ?? this.supporterUnlocked,
      );

  factory Settings.fromJson(Map<String, dynamic> json) => Settings(
        telemetryEnabled: json['telemetryEnabled'] as bool? ?? true,
        supporterUnlocked: json['supporterUnlocked'] as bool? ?? false,
      );

  Map<String, dynamic> toJson() => {
        'telemetryEnabled': telemetryEnabled,
        'supporterUnlocked': supporterUnlocked,
      };
}

/// settings.json store with BoardStore's exact durability pattern:
/// tmp+rename atomic writes; corrupt file set aside as .corrupt + defaults.
class SettingsStore {
  SettingsStore(this._dir);
  final Directory _dir;

  File get _file => File('${_dir.path}/settings.json');

  Future<Settings> load() async {
    if (_file.existsSync()) {
      try {
        return Settings.fromJson(
            jsonDecode(await _file.readAsString()) as Map<String, dynamic>);
      } catch (_) {
        // Keep the broken file for diagnosis, fall back to defaults.
        try {
          _file.renameSync('${_file.path}.corrupt');
        } catch (_) {}
      }
    }
    return const Settings();
  }

  Future<void> save(Settings settings) async {
    try {
      final tmp = File('${_file.path}.tmp');
      await tmp.writeAsString(jsonEncode(settings.toJson()), flush: true);
      tmp.renameSync(_file.path);
    } catch (_) {
      // Persistence must never take down the app; in-memory settings stand.
    }
  }
}

final settingsStoreProvider = Provider<SettingsStore>(
    (ref) => throw UnimplementedError('override in main'));

final settingsProvider =
    AsyncNotifierProvider<SettingsNotifier, Settings>(SettingsNotifier.new);

class SettingsNotifier extends AsyncNotifier<Settings> {
  @override
  Future<Settings> build() => ref.read(settingsStoreProvider).load();

  Settings get _settings => state.value ?? const Settings();

  Future<void> _update(Settings next) async {
    state = AsyncData(next);
    await ref.read(settingsStoreProvider).save(next);
  }

  Future<void> setTelemetryEnabled(bool enabled) =>
      _update(_settings.copyWith(telemetryEnabled: enabled));

  Future<void> setSupporterUnlocked(bool unlocked) =>
      _update(_settings.copyWith(supporterUnlocked: unlocked));
```

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
```

```dart
/// The CLOSED parent-mode event taxonomy. This enum IS the analytics schema:
/// there is no free-text event path, and the only parameter ever sent is a
/// language code. Card labels, recordings, photos, typed text, and child tap
/// contents never leave the phone in any channel.
enum ParentEvent {
  languageChanged,
  customCardAdded,
  recordingCreated,
  morePageConfigured,
  backupCreated,
  backupRestored,
  insightsViewed,
  supporterPurchased,
  supporterRestored,
}

/// Parent-mode-only telemetry. In the sideload channel the default sink is
/// null, making log() a compiled no-op. NOTHING under lib/features/board/
/// may import this file (guard-tested).
class TelemetryService {
  TelemetryService(
      {Future<void> Function(String name, Map<String, String> params)? send})
      : _send = send ??
            (appChannel == AppChannel.store ? _firebaseSend : null);

  final Future<void> Function(String name, Map<String, String> params)? _send;

  static const _names = {
    ParentEvent.languageChanged: 'language_changed',
    ParentEvent.customCardAdded: 'custom_card_added',
    ParentEvent.recordingCreated: 'recording_created',
    ParentEvent.morePageConfigured: 'more_page_configured',
    ParentEvent.backupCreated: 'backup_created',
    ParentEvent.backupRestored: 'backup_restored',
    ParentEvent.insightsViewed: 'insights_viewed',
    ParentEvent.supporterPurchased: 'supporter_purchased',
    ParentEvent.supporterRestored: 'supporter_restored',
  };

  static Future<void> _firebaseSend(
          String name, Map<String, String> params) =>
      FirebaseAnalytics.instance.logEvent(name: name, parameters: params);

  Future<void> log(ParentEvent event,
      {Map<String, String> params = const {}}) async {
    final send = _send;
    if (send == null) return; // sideload: telemetry does not exist
    try {
      await send(_names[event]!, params);
    } catch (_) {
      // Telemetry must never break the app.
    }
  }
}
```

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';

/// The one and only product: a one-time non-consumable supporter unlock.
/// Core communication (cards, speech, languages, recordings, backup) is
/// NEVER gated — the unlock buys the insights PDF export and grandfathered
/// access to future premium extras.
const supporterProductId = 'bolo_supporter_unlock';

/// Thin seam over the in_app_purchase plugin (mirrors the Tts seam): tests
/// fake this; only the adapter below touches the platform.
abstract class PurchaseGateway {
  Stream<List<PurchaseDetails>> get purchaseStream;
  Future<bool> isAvailable();
  Future<ProductDetailsResponse> queryProductDetails(Set<String> ids);
  Future<void> buyNonConsumable(ProductDetails product);
  Future<void> restorePurchases();
  Future<void> completePurchase(PurchaseDetails purchase);
}

class InAppPurchaseGateway implements PurchaseGateway {
  final InAppPurchase _iap = InAppPurchase.instance;

  @override
  Stream<List<PurchaseDetails>> get purchaseStream => _iap.purchaseStream;
  @override
  Future<bool> isAvailable() => _iap.isAvailable();
  @override
  Future<ProductDetailsResponse> queryProductDetails(Set<String> ids) =>
      _iap.queryProductDetails(ids);
  @override
  Future<void> buyNonConsumable(ProductDetails product) => _iap
      .buyNonConsumable(purchaseParam: PurchaseParam(productDetails: product));
  @override
  Future<void> restorePurchases() => _iap.restorePurchases();
  @override
  Future<void> completePurchase(PurchaseDetails purchase) =>
      _iap.completePurchase(purchase);
}

class PurchaseService {
  PurchaseService(this._gateway, {required this.onUnlocked});

  final PurchaseGateway _gateway;

  /// Called on entitlement: restored=false for a fresh purchase, true for a
  /// restore. Persists supporterUnlocked — OFFLINE-FOREVER: once stored in
  /// settings.json it is never re-checked online.
  final Future<void> Function({required bool restored}) onUnlocked;

  StreamSubscription<List<PurchaseDetails>>? _sub;

  void start() {
    _sub ??= _gateway.purchaseStream.listen(_onPurchases);
  }

  Future<void> _onPurchases(List<PurchaseDetails> purchases) async {
    for (final p in purchases) {
      final unlocks = p.productID == supporterProductId &&
          (p.status == PurchaseStatus.purchased ||
              p.status == PurchaseStatus.restored);
      if (unlocks) {
        try {
          await onUnlocked(restored: p.status == PurchaseStatus.restored);
        } catch (_) {
          // Entitlement persistence failure must not stop completePurchase.
        }
      }
      // ALWAYS complete — regardless of status or product. Uncompleted
      // purchases are redelivered by the store forever.
      if (p.pendingCompletePurchase) {
        try {
          await _gateway.completePurchase(p);
        } catch (_) {}
      }
    }
  }

  Future<void> buy() async {
    if (!await _gateway.isAvailable()) return;
    final resp = await _gateway.queryProductDetails({supporterProductId});
    final matches =
        resp.productDetails.where((d) => d.id == supporterProductId);
    if (matches.isEmpty) return;
    await _gateway.buyNonConsumable(matches.first);
  }

  Future<void> restore() => _gateway.restorePurchases();

  void dispose() {
    _sub?.cancel();
    _sub = null;
  }
}

final purchaseGatewayProvider = Provider<PurchaseGateway>(
    (ref) => throw UnimplementedError('override in main (store channel only)'));

final purchaseServiceProvider = Provider<PurchaseService>((ref) {
  final service = PurchaseService(
    ref.watch(purchaseGatewayProvider),
    onUnlocked: ({required bool restored}) async {
      await ref.read(settingsProvider.notifier).setSupporterUnlocked(true);
      await ref.read(telemetryProvider).log(restored
          ? ParentEvent.supporterRestored
          : ParentEvent.supporterPurchased);
    },
  );
  ref.onDispose(service.dispose);
  return service;
});
```

```dart
import 'dart:typed_data';
import 'package:pdf/pdf.dart';
import 'package:pdf/widgets.dart' as pw;
import '../models/board.dart';
import 'usage_store.dart';

/// One-page usage summary for handing to a therapist. Labels render in
/// English: package:pdf's built-in fonts have no Arabic-script glyphs and
/// shipping font files is deliberately out of scope for v3.
Future<Uint8List> buildInsightsPdf(UsageData usage, Board board) async {
  final now = DateTime.now();
  final enLabels = {
    for (final cat in board.categories)
      for (final card in [...cat.cards, ...cat.moreCards])
        card.id: card.labels['en'] ?? card.id,
  };
  final categoryOf = {
    for (final cat in board.categories)
      for (final card in [...cat.cards, ...cat.moreCards])
        card.id: cat.names['en'] ?? cat.id,
  };

  final weekCount = usage.perDay.entries
      .where((e) => DateTime.parse(e.key)
          .isAfter(now.subtract(const Duration(days: 7))))
      .fold<int>(0, (sum, e) => sum + e.value);
  final top = usage.perCard.entries.toList()
    ..sort((a, b) => b.value.count.compareTo(a.value.count));
  final top10 = top.take(10).toList();
  final newWords = usage.perCard.entries
      .where((e) => e.value.firstUsed
          .isAfter(now.subtract(const Duration(days: 14))))
      .map((e) => enLabels[e.key] ?? e.key)
      .toList();
  final perCategory = <String, int>{};
  for (final e in usage.perCard.entries) {
    final cat = categoryOf[e.key] ?? 'Removed cards';
    perCategory[cat] = (perCategory[cat] ?? 0) + e.value.count;
  }

  final doc = pw.Document();
  doc.addPage(pw.Page(
    pageFormat: PdfPageFormat.a4,
    build: (context) => pw.Column(
      crossAxisAlignment: pw.CrossAxisAlignment.start,
      children: [
        pw.Text('Bolo — usage insights',
            style:
                pw.TextStyle(fontSize: 20, fontWeight: pw.FontWeight.bold)),
        pw.Text('Generated ${_day(now)} · on-device data only'),
        pw.SizedBox(height: 12),
        pw.Text('Words this week: $weekCount'),
        pw.SizedBox(height: 8),
        pw.Text('Most used words',
            style: pw.TextStyle(fontWeight: pw.FontWeight.bold)),
        pw.TableHelper.fromTextArray(
          headers: ['Word', 'Taps', 'First used', 'Last used'],
          data: [
            for (final e in top10)
              [
                enLabels[e.key] ?? e.key,
                '${e.value.count}',
                _day(e.value.firstUsed),
                _day(e.value.lastUsed),
              ],
          ],
        ),
        pw.SizedBox(height: 8),
        pw.Text(
            'New words (last 14 days): ${newWords.isEmpty ? 'none' : newWords.join(', ')}'),
        pw.SizedBox(height: 8),
        pw.Text('Taps per category',
            style: pw.TextStyle(fontWeight: pw.FontWeight.bold)),
        for (final e in perCategory.entries)
          pw.Text('${e.key}: ${e.value}'),
      ],
    ),
  ));
  return doc.save();
}

String _day(DateTime d) =>
    '${d.year.toString().padLeft(4, '0')}-${d.month.toString().padLeft(2, '0')}-${d.day.toString().padLeft(2, '0')}';
```
